> **用途**：帮助讲师和助教备课、控场、评分和处理现场问题。
> **注意**：本目录是内部入口，不建议整体发给学员。

---

## 二、可发给学员的材料入口

学员材料从这里开始：

```text
../student-pack/README.md
```

不要直接把以下文件完整发给学员：

- `../workshop-outline.md`
- `../instructor-quickref.md`
- `../group-evaluation.md`
- `../pre-workshop-survey.md`

原因：这些文件包含讲师话术、翻车设计、应急安排、评分汇总和问卷解读方法。

---

## 三、课堂分发节奏

| 时间 | 分发材料 | 讲师动作 |
|------|----------|----------|
| 课前 3-7 天 | 学员包 README、课前准备、学员版问卷 | 收集环境问题和场景偏好 |
| 上午讲解后 | Prompt / Context / Harness 三份参考材料 | 只讲关键模板，不逐页讲 |
| 下午实战前 | 场景任务卡目录、对应任务卡、学员版评价说明 | 先让学员读任务卡顶部的5分钟速用框，再明确成果要求和汇报时间 |
| 课后 | 学员包 + 本组任务卡 + 方法论手册 | 鼓励学员迁移到自身业务场景 |

---

## 四、现场控场原则

- 环境问题不占用全班时间，2 分钟内无法解决就两人一机。
- 保留“翻车 -> 发现 -> 加 Harness 纠正”的教学设计。
- 不把工具差异讲成重点，重点始终是 Prompt / Context / Harness。
- 金融/投资类任务不得让 Agent 输出买入、卖出、持有、目标价等建议。
