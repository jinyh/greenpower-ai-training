## 目录划分

```
raw/
├── 教程/   网页教程离线包
├── 框架/   开源 Agent 框架的 git clone
```

| 链接 | 失败原因 | 已尝试 | 当前判定 |
|---|---|---|---|
| R-B1 substack | 连接超时 | wget × 2、curl + UA、WebFetch | 已放弃，标 STATUS.md |
| R-B2 besthub | HTTP 403 (Cloudflare) | wget × 2、curl + UA + Referer、WebFetch | 已放弃，标 STATUS.md |
| R-B10 ~ R-B18（Medium × 9） | 连接超时 | wget × 2、curl + UA、freedium 镜像、archive.org wayback、WebFetch | 已放弃，标 STATUS.md |

放弃原因汇总：

- 本地直连 medium.com / substack.com 30 秒超时，非偶发抖动
- `freedium.cfd` 域名当前网络无法解析
- `archive.org` Wayback API 无响应
- WebFetch 工具被 claude.ai 安全策略层面拒绝（域名未列入允许列表）
- besthub 是次级聚合站，原文为转载，性价比不足以走人工兜底

分级清单中将这 11 条按"摘要不可得"处理（标 D 或 C，仅保留 ref.md 链接）。
