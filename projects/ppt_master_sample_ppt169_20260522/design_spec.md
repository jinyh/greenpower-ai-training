# Design Specification

## I. Canvas

- Format: PPT 16:9
- Size: 1280 x 720
- Margin: 72 px

## II. Visual Direction

Blue-gray academic teaching deck for MBA learners. Use quiet structure, strong information hierarchy, editable SVG text, and visual density close to the reference deck.

## III. Core Motif

Deep blue cover with subtle brain/circuit lines. Content pages use light gray background, blue icons, parallelogram labels, tables/cards, and bottom teaching insight strips.

## IV. Typography

Use PingFang SC / Microsoft YaHei fallback for Chinese text. Titles are large and calm; body text is compact and left-aligned.

## V. Color System

Primary blue `#0866D8`; navy `#0B2540`; light background `#EEF2F7`; text `#304763`; body `#5B6775`; orange accent `#F47A1F`.

## VI. Page Roster

1. Cover: Agent 是杠杆，不是替代
2. Framework: Prompt / Context / Harness
3. Harness Loop: 翻车 -> 发现 -> 加 Harness -> 复核
