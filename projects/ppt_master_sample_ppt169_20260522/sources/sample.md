# AI Agent Hands on Lab 样本

Deck: AI Agent Hands on Lab
Audience: 中欧商学院 MBA
Style: 参考 ppt-ref 的蓝灰学术风格，文字保持可编辑，图形用 SVG 手写。

## 01. Agent 是杠杆，不是替代

- 今天不讲算法，不讲代码，讲如何让 AI 帮你完成执行性工作
- Agent 的价值是放大执行力，不是替代判断力
- 今日带走三个问题：能力边界、能力盲区、驾驭方法

## 02. 驾驭 Agent 的三要素

- Prompt：结构化任务指令书
- Context：Agent 的视野和记忆
- Harness：防止跑偏和幻觉的规则系统
- Prompt 定方向，Context 定质量，Harness 定边界

## 03. Harness：把翻车变成学习材料

- 输出格式约束：让结果可读、可复制、可评分
- 边界约束：只基于给定材料，未提及就标注
- 校验机制：列出不确定点、异常数据和信息缺口
